## paramiko_ssh connection plugin (M018)

paramiko_ssh connection plugin is deprecated; use ssh connection instead (removed in 2.21)

**Removal version**: 2.21
**Fix tier**: 1
**Audience**: content

### Detection

Detect connection: paramiko_ssh or ansible_connection: paramiko_ssh

### Example: violation

```yaml
- name: Example play
  hosts: all
  connection: paramiko_ssh
  tasks:
    - name: Ping
      ansible.builtin.ping:
```

### Example: pass

```yaml
- name: Example play
  hosts: all
  connection: ssh
  tasks:
    - name: Ping
      ansible.builtin.ping:
```

### Remediation

Direct substitution
