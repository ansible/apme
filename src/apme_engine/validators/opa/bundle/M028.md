## first_found auto-splitting paths (M028)

first_found lookup auto-splitting paths on delimiters is deprecated (2.23)

**Removal version**: 2.23
**Fix tier**: 1
**Audience**: content

### Detection

Detect first_found terms containing comma or colon delimiters

### Example: violation

```yaml
- name: Find file
  ansible.builtin.debug:
    msg: "{{ lookup("first_found", "a.yml,b.yml") }}"
```

### Example: pass

```yaml
- name: Find file
  ansible.builtin.debug:
    msg: "{{ lookup("first_found", ["a.yml", "b.yml"]) }}"
```

### Remediation

Split string term into YAML list
