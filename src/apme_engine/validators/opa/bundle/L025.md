## Name casing

Task/play name should start with uppercase.

This includes handler names and named task blocks. Only identified Ansible
content is checked; collection metadata, dependency identifiers, and variable
values are not task labels. Name casing is applied by L025 remediation when
the rule is enabled. Standalone YAML formatting preserves name values.

### Example: violation

```yaml
- name: my play
  hosts: localhost
  tasks:
    - name: do something
      ansible.builtin.debug:
        msg: hi
```

### Example: pass

```yaml
- name: My play
  hosts: localhost
  tasks:
    - name: Do something
      ansible.builtin.debug:
        msg: hi
```
