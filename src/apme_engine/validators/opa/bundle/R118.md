## Inbound transfer (R118)

Detects remote or potentially remote sources covered by APME's local inbound
module profiles. During OPA serialization, the payload builder derives a
`risk_type: inbound_transfer` annotation for `get_url`, `git`, `subversion`,
and `unarchive` tasks (which require `remote_src: true`). Templated sources are treated
as potentially remote; local paths and `file://` sources are skipped. This
does not load ARI's annotation registry or cover third-party modules
automatically.

### Example: violation

```yaml
- name: Download artifact
  ansible.builtin.get_url:
    url: https://example.com/file.tar.gz
    dest: /tmp/file.tar.gz
```

### Example: pass

```yaml
- name: No download
  ansible.builtin.debug:
    msg: hello
```
