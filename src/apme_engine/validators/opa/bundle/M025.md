## Third-party strategy plugin (M025)

Third-party strategy plugins are deprecated; only ansible.builtin strategies are supported (2.23)

**Removal version**: 2.23
**Fix tier**: 3
**Audience**: content

### Detection

Detect strategy: not in ansible.builtin.*

### Example: violation

```yaml
- name: Example play
  hosts: all
  strategy: mitogen_linear
  tasks:
    - name: Ping
      ansible.builtin.ping:
```

### Example: pass

```yaml
- name: Example play
  hosts: all
  strategy: linear
  tasks:
    - name: Ping
      ansible.builtin.ping:
```

### Remediation

Informational warning only
