## Argspec validation — mock/patch (L059)

Loads the module's Python file and patches `AnsibleModule.__init__` to capture its `argument_spec`. This can reflect the runtime argument definitions more closely than L058, but imports module code. It checks unsupported parameters, required parameters, choices, mutually exclusive groups, and required-together groups. It does not enforce argument types, `required_if`, or `required_one_of`.

Tasks with any module option containing `{{` are skipped. Module defaults are not merged into the task arguments before validation.
Short module names in tasks whose collection search order includes custom
collections are also skipped because this argspec pass does not resolve the
collection-specific plugin. Fully qualified names are still checked.

### Example: violation

```yaml
- name: Example play
  hosts: localhost
  connection: local
  tasks:
    - name: Bad args
      ansible.builtin.file:
        path: /tmp/foo
        invalid_param: true
```

### Example: pass

```yaml
- name: Example play
  hosts: localhost
  connection: local
  tasks:
    - name: Good args
      ansible.builtin.file:
        path: /tmp/foo
        state: touch
```
