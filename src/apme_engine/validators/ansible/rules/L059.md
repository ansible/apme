## Argspec validation — mock/patch (L059)

Loads the module's Python file and patches `AnsibleModule.__init__` to capture its `argument_spec`. This can reflect the runtime argument definitions more closely than L058, but imports module code. It checks unsupported parameters, required parameters, choices, mutually exclusive groups, and required-together groups. It does not enforce argument types, `required_if`, or `required_one_of`.

Uses the same inherited module-defaults preparation as L058, including play,
block, task, role/include contexts, empty-entry resets, and action groups.
Explicit task arguments follow defaults; Ansible parameter-alias precedence
applies afterwards. Authored graph arguments are never modified.

The service reports unavailable defaults context through L058 and excludes only
those invocation contexts from both checks. Direct L059 callers receive the
same coverage notices with L059. The defaults resolver uses installed metadata
and does not evaluate templates or execute playbooks/project plugins; L059's
existing module spec capture still imports installed module code. Findings using
inherited defaults require manual review to protect the enclosing declaration.

Literal keys/values and definite argument-group errors remain checked alongside
templated values. Dynamic values may become `omit`, so they cannot establish
definite presence for unsupported-argument or argument-group errors; their choice
checks are skipped. Templated task-level `args`
mappings remain skipped. For tasks without defaults, short module names in a
custom collection search context remain skipped; fully qualified names are checked.

### Example: violation

```yaml
- name: Example play
  hosts: localhost
  connection: local
  tasks:
    - name: Bad args
      ansible.builtin.file:
        path: /tmp/foo
        invalid_param: true
```

### Example: pass

```yaml
- name: Example play
  hosts: localhost
  connection: local
  tasks:
    - name: Good args
      ansible.builtin.file:
        path: /tmp/foo
        state: touch
```
