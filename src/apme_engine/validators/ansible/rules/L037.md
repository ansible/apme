## Unresolved module (L037)

Reports a task module name when ansible-core's module and action plugin loaders
cannot resolve it in the scan environment. Resolution uses the task's in-scope
`collections` search order and runs from the scan root so project-level
`ansible.cfg` plugin paths are available. Valid short names resolvable through
those paths are accepted. Role-specific plugin paths are not inferred for
each task. Removed modules are reported as M004 instead.

### Example: violation

```yaml
- name: Typo in module
  ansible.builtin.copyyy:
    src: a
    dest: /tmp/b
```

### Example: pass

```yaml
- name: Copy file
  ansible.builtin.copy:
    src: a
    dest: /tmp/b
```
