## Syntax check (L057)

Runs `ansible-playbook --syntax-check` on each playbook found under the project root. Reports any syntax errors detected by Ansible itself (e.g. invalid YAML, unknown modules at parse time, missing imports).

Molecule scenario playbooks and references that Native L115-L119 assessed
statically are excluded, because runtime syntax checking would evaluate Molecule
project lookups. When a Molecule reference needs unavailable runtime context,
the identified scenario content stays excluded and the remaining playbooks are
still checked; the residual coverage limit is reported as an advisory (`info`)
rather than suppressing every runtime check.

### Example: violation

```yaml
- name: Bad playbook
  hosts: localhost
  connection: local
  tasks:
    - name: Broken task
      ansible.builtin.debug:
        msg: {{ unquoted_jinja }}
```

### Example: pass

```yaml
- name: Good playbook
  hosts: localhost
  connection: local
  tasks:
    - name: Working task
      ansible.builtin.debug:
        msg: "Hello world"
```
