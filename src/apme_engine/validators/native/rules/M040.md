## Removed Python inventory keyword (M040)

Remove the `disable_lookups` keyword from calls to `_compose()` in Python
inventory plugins targeting ansible-core 2.23 or newer. The keyword has no
effect in versions that still accept it. Native parses the uploaded source
without importing or running the plugin. M047 covers constructed inventory
YAML instead.

### Example: violation

```yaml
plugins/inventory/example.py: |
  class InventoryModule:
      def parse(self, template, variables):
          return self._compose(template, variables, disable_lookups=False)
```

### Example: pass

```yaml
plugins/inventory/example.py: |
  class InventoryModule:
      def parse(self, template, variables):
          return self._compose(template, variables)
```
