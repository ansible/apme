## Molecule context (L118)

Explain validation that cannot be completed from the supplied snapshot. Host environment variables, external files, driver packages, and untrusted plugins are never loaded. Supplied `.env.yml` values and known Molecule path variables may be resolved. This is a coverage notice, not proof of invalid content.

Unavailable collection-qualified playbook imports need collection context.
Known generated Molecule paths are recognized in arguments without a notice;
references requiring the generated files' contents remain incomplete.

Enabled automatically; default severity is medium (warning). Existing APME rule
configuration can change severity or disable the finding. Configuration findings
require manual review and are not sent to a task remediation transform.

Notices that also fire on valid, common configuration are labelled `info`: an
external driver without a bundled driver schema, and verifier code that is not
Ansible playbooks. Those scenarios are supported; the notice only records what
was not assessed. Notices about values or files that could not be resolved stay
`medium`, because checks were skipped rather than passed. Severity labels the
finding; it does not change `apme check`'s exit status.

Compatibility target: Molecule 24.9.0+. Legacy and native configuration use
bundled 24.9.0 and 26.11.0 profiles respectively, selected from merged supplied
configuration. Profiles describe syntax compatibility, not vendor support for
every upstream release or driver.

Examples below are uploaded snapshot maps: each key is a relative file path and
each literal value is that file's contents. The violation example expects a
coverage notice for unavailable context, rather than proof of invalid content.

### Example: violation

```yaml
molecule/default/molecule.yml: |
  provisioner:
    playbooks:
      converge: ${EXTERNAL_PLAYBOOK}
```

### Example: pass

```yaml
molecule/default/molecule.yml: |
  provisioner:
    playbooks:
      converge: converge.yml
molecule/default/converge.yml: |
  - name: Converge
    hosts: all
    tasks: []
```

For a directory assessment, include the shared config and referenced files.
A single-file assessment cannot establish whether references exist outside its
snapshot. See [Molecule validation guide](../../../../../docs/guides/MOLECULE.md).
