## Molecule context (L115)

Explain validation that cannot be completed from the supplied snapshot. Host environment variables, external files, driver packages, and untrusted plugins are never loaded. Supplied `.env.yml` values and known Molecule path variables may be resolved. This is a coverage notice, not proof of invalid content.

Enabled automatically; default severity is medium (warning). Existing APME rule
configuration can change severity or disable the finding. Configuration findings
require manual review and are not sent to a task remediation transform.

Compatibility baseline: Molecule 24.9.0, documented as distributed with Red Hat
AAP 2.5 Ansible development tools. This is a schema compatibility statement,
not a claim that every upstream 6+ build or driver has Red Hat support.

### Example: violation or incomplete assessment

```yaml
provisioner:
  playbooks:
    converge: ${EXTERNAL_PLAYBOOK}
```

### Example: pass with referenced files supplied

```yaml
provisioner:
  playbooks:
    converge: converge.yml
```

For a directory assessment, include the shared config and referenced files.
A single-file assessment cannot establish whether references exist outside its
snapshot. See [Molecule validation guide](../../../../../docs/guides/MOLECULE.md).
