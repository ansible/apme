## Inventory group hyphens (L111)

Inventory group names should use underscores instead of hyphens.

Group names with hyphens cause issues when accessed via Jinja2 dot notation
because `groups.web-servers` is parsed as `groups.web` minus `servers`, not as
access to the `web-servers` group. Use `web_servers` instead of `web-servers`.

Addresses [AAPRFE-2997](https://issues.redhat.com/browse/AAPRFE-2997).

### Example: violation

**INI format:**

```ini
[web-servers]
host1.example.com

[db-servers:children]
primary-db
replica-db
```

**YAML format:**

```yaml
all:
  children:
    web-servers:
      hosts:
        host1.example.com:
    production-env:
      children:
        web-servers:
```

### Example: pass

**INI format:**

```ini
[web_servers]
host1.example.com

[db_servers:children]
primary_db
replica_db
```

**YAML format:**

```yaml
all:
  children:
    web_servers:
      hosts:
        host1.example.com:
    production_env:
      children:
        web_servers:
```

### Why this matters

- `groups['web-servers']` works but `groups.web-servers` is parsed as subtraction
- Jinja2 dot notation does not access the hyphenated group name
- Inconsistent access patterns lead to maintenance issues
- Collection best practices recommend Python-identifier-compatible names
